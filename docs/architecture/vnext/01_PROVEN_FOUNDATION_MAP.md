## Proven chain

```text
Supabase principal
  -> AuthorityContext
  -> tenant-owned transaction/asset/base version
  -> TaskSpec + ExecutionAuthority + MutationLease
  -> ExecutionRun
  -> CandidateAsset / EvidenceReceipt / PreservationRun
  -> criterion evidence + Same-Spec Gate + VerificationRun
  -> durable Human Acceptance
  -> current OWNER and tenant locks in commit RPC
  -> AssetVersion + StateCommit + COMMITTED
```

The chain begins with an already formed transaction/specification. Signal
sufficiency before that point is not represented as a durable domain boundary.
