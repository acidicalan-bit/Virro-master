# Evidence Matrix

The E1 harness covers migration-count preflight, canonical ACL measurement,
and the TypeScript/PostgreSQL canonical JSON hash matrix when PostgreSQL 17 is
available. The full positive D5 graph, expiry, semantic substitution,
concurrency, tamper, predecessor, OCI, and preview gates require the native
CI environment. They must remain `NOT_RUN` or `BLOCKED` until observed; no
manual PASS values are authored.
