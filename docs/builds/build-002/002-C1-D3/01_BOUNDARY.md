# Authority Boundary

The public service accepts only `AuthorityContext` and `authorityCommitId`.
D2 currentness is preflight. The authoritative decision is the
`build002_admit_delegability` SECURITY DEFINER RPC, which rechecks tenant,
membership, marker, transaction, asset/version, C0 binding, published
blueprint/profile, and the signal/requirement sets while holding deterministic
locks and table SHARE locks. PostgreSQL controls relational exactness and
atomic visibility; TypeScript controls canonical hashes.
